# Untold Vault ✨  
*A place for words meant for only one soul.*

Untold Vault is a minimal, elegant web application designed for sharing deeply personal messages — securely, privately, and temporarily.  
Each secret is protected by intention: a password, an expiry, and a single private link.

No feeds.  
No permanence.  
Only what is meant to be seen — once.

---

## ✦ Why Untold Vault

Some words are not meant to live forever.  
Some messages are meant for one person — and one moment.

Untold Vault exists for:
- Confessions
- Goodbyes
- Promises
- Truths you don’t want archived

---

## ✦ Core Features

- 🔐 **Password-protected secrets**  
- ⏳ **Custom expiry date (expires at the end of the selected day)**  
- 🔗 **Private, shareable links**  
- 🌗 **Light & Dark mode with subtle motion**  
- ✨ **Soft animations and gold-accent interactions**  
- 🗑️ **Automatic deletion after expiry**

No accounts.  
No tracking.  
No noise.

---

## ✦ Experience Design

Untold Vault focuses on **emotional UX**, not just functionality.

- Calm, ballet-inspired color palette  
- Soft shadows and restrained motion  
- Gold accents that respond gently to interaction  
- Visual cues for expiry and impermanence  

Every element is designed to feel intentional — never loud.
